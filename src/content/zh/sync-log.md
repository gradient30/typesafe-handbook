# 同步日志

> 每次对照官网后单独记一条：改了什么、本站哪一页。最新的永远在最上面。

GitHub Actions 每 6 小时拉取 [docs.typesafe.ai/llms.txt](https://docs.typesafe.ai/llms.txt) 和各页 Markdown，算出 SHA-12。和上一份指纹不一样，就新增一条日志。

每一行都写清四件事：

1. **类型**：首次全量 / 新增 / 改动 / 删除
2. **改了什么**：中文标题和 slug
3. **在 Web 哪个位置**：侧栏哪一区、哪一项，以及本站 URL
4. **说明**：哈希变化或「中文尚未翻译」

顶栏的「同步」日期就是最近一次对照。点进去就是本页。

食谱实验日志很长，中文站给的是架构、结论和关键代码，不是把 30–70 KB 的 notebook 逐行搬过来。概念页（简介、原语、模式、SDK、API）是完整译本。
