# 同步日志

> 每次对照官网后单独记一条：改了什么、本站哪一页。最新的永远在最上面。

每天 09:00（北京时间）例行对照 [docs.typesafe.ai/llms.txt](https://docs.typesafe.ai/llms.txt) 和各页 Markdown。哈希变了就重译对应中文页，并在本页新增一条日志。6 小时指纹任务只负责提前标出「待更新」，真正的汉化走每日例行。

每一行都写清四件事：

1. **类型**：首次全量 / 例行对照 / 已汉化 / 新增 / 改动 / 删除
2. **改了什么**：中文标题和 slug
3. **在 Web 哪个位置**：侧栏哪一区、哪一项，以及本站 URL
4. **说明**：哈希变化、已重译，或「中文尚未翻译」

顶栏的「同步」日期就是最近一次对照。点进去就是本页。

食谱实验日志很长，中文站给的是架构、结论和关键代码，不是把 30–70 KB 的 notebook 逐行搬过来。概念页（简介、原语、模式、SDK、API）是完整译本。
