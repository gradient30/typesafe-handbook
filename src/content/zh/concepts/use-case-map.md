# 用例地图

> 按行业浏览 TypeSafe 用例，把想法变成软件工作流。

用地图来想：TypeSafe 能嵌进你所在行业的哪里。打开最接近的行业，扫一遍示例决策，再改成你自己流程里的文档和动作。

## 用例大类

**AI 自动化软件。** 把 AI 嵌进可靠软件，让它在后台跑一百万次也不需要人副驾。控制流归代码（不是 markdown 文件），TypeSafe 负责语义决策和语言理解。

**实时应用。** 前沿智力跑在约 150ms 的实时速度上，决策快过人的感知。快而且够聪明，可以写进游戏，也可以嵌进 UI。

**大数据上的 AI Map Reduce。** 便宜 100 倍，就能处理巨型数据集：在巨大语料里检索相关信息、给巨大的 agent trace 分类、抽特征做预测。

**通用校验。** 校验任意其他 AI 的输入提示、抽取结果、推理轨迹、工具调用或其他输入。发现越狱、引用错误、幻觉、失误，以及其他 LLM 的出错模式，成本只是那次 LLM 调用的零头。

**Harness 工程。** 用 Jev 查询把 harness 做聪明：模型路由、语义上下文检索、LLM 错误检测和护栏、推理轨迹分类——光速、成本只是零头。

## 自动化用例示例

### 搜索与检索

* 在 RAG 流水线里用语义搜索、打分、排序替换或补充 embeddings。
* 给 query 与候选的相关性打分。
* 用成对比较重排结果。
* 对 query 和候选做交叉编码，提高精度。
* 为下游 AI 工作流选出有用的上下文。

### 科学发现

* 按纳入 / 排除标准筛论文，做系统综述。
* 用预定主题或类别，给访谈记录、开放题问卷、田野笔记里的段落打标签。
* 核对手稿和生成摘要里，被引段落是否支撑主张。
* 标出缺失的方法细节：对照、数据集描述、实验设置。
* 跨论文识别实体和关系，建研究知识图谱，把发现链到支撑段落。

### 模型路由

* 用 Jev 做自定义路由器，决定每条 prompt 交给哪个 LLM。
* 为你的工作流设路由规则和阈值。
* 分类意图和领域。
* 估计难度和风险。
* 把需要更贵模型的请求升级上去。

### LLM 护栏

* 在每次 LLM 输入、输出和工具调用上放语义检查，成本只是那次 LLM 调用的零头。
* 检测越狱和 prompt 注入。
* 识别政策违规和敏感数据暴露。
* 实时发现工具调用错误和回复质量失败。
* 把结构化检查结果和概率记下来，让 AI 系统和 harness 的故障更好追。

### 语义代码 lint

* 用 Jev 查询给代码和写作加上自动语义 lint。
* 按团队的编码约定和写作规范定义检查。
* 在 CI 里跑，把违规标出来复核。

### 给预测模型抽特征

* 用 Jev 从自然语言数据里抽概率特征。
* 把这些特征和结构化数据合在一起，训练有真实标签的任务。
* 用自动研究工作流提出特征定义，对着留出集上的真实标签评估预测价值。

### 招聘

* 按明确、与岗位相关的标准评估简历、申请和面试反馈。
* 识别相关经历。
* 给所需能力的证据打分。
* 把候选人匹配到岗位。
* 路由给招聘经理或 recruiter。
* 不确定的案子升级给人工复核。

### 线索生成

* 把公司资料、高管履历、入库消息匹配到理想客户画像。
* 给行业契合度和公司成熟度打分。
* 检测买家相关度、痛点和购买意向。
* 给线索排序并路由。

### 客户支持

* 按问题、产品线、客户意图给入库工单分类。
* 处理通话记录，抽出客户问题、承诺和后续动作。
* 检测紧急程度、沮丧、流失风险和退款请求。
* 把案子路由到正确的团队、队列或自动流程。
* 对照政策和客户请求，核验支持回复。

### 保险理赔

* 给出险通知、查勘笔记和证明材料分类。
* 检测案件复杂度、缺失信息和潜在欺诈信号。
* 给直通处理或专家复核排出优先级。
* 不确定或高风险案子升级给人工查勘员。

### 金融犯罪

* 评估交易叙述、KYC 材料和告警历史里的可疑特征。
* 在不一致的姓名、档案和记录之间对齐实体。
* 按风险、相关度和证据质量给告警排序。
* 把含糊案子路由给调查人员复核。

### 法律与合规

* 给合同、政策、监管申报和营销主张分类。
* 检测缺失条款、违禁主张和政策违规。
* 对照明确的法律或合规要求核验文档。
* 把高风险或不确定的发现升级给法务或合规团队。

### 电商市场

* 在不一致的卖家目录之间分类并归一化商品列表。
* 从标题和描述里抽商品属性。
* 检测违禁上架、仿品信号、评价滥用和政策违规。
* 给商品排序，不确定的列表交给人工复核。

### 审核与信任安全

* 用公司特有、带细微差别的标准，决定哪些帖子达到你的审核门槛。
* 审核社区、客服和 SDR 流程里的用户内容和自动对话。
* 检测毒性、骚扰、垃圾、欺诈、不安全建议、个人数据暴露、退订请求和违规主张。
* 把严重度和置信度合在一起，决定放行、警告、复核或拦截。

### 广告

* 评估创意资产、投放文案、落地页和版位上下文。
* 分类品牌安全和受众适配。
* 检查监管合规和违禁主张。
* 评估创意质量，以及广告与落地页是否对齐。

### 游戏

* 评估玩家举报、局内聊天、评价和支持对话。
* 审核聊天，检测辱骂、毒性或可疑行为。
* 给内容标注，给沮丧或投入度打分。
* 检测流失信号，路由玩家支持请求。

### 风险评估

* 把事故报告、理赔笔记、交易描述和供应商评估转成概率风险指标。
* 用这些指标接入保险和核保流程。
* 分类风险类型，检测可疑特征。
* 给严重度打分，排出复核优先级。
* 为更大的风险模型抽特征。

### 需求预测

* 用客户问询、销售笔记、产品评价、支持工单和市场报告里的语义信号，给预测模型加料。
* 抽出购买意向、紧急程度和产品兴趣。
* 检测供应担忧、竞争压力和新兴需求主题。
* 把这些特征和历史时间序列一起喂进预测模型。

### 图与知识图谱

* 用类型化语义决策给知识图谱做标注和核验。
* 分类关系和实体类型。
* 检测记录或主张之间的矛盾。
* 支持概率遍历和层级分类。

## 任务形态示例

| 决策形态 | 什么时候用 | 例子 |
| --- | --- | --- |
| **分类** | 已知类别里该有一个胜出 | 意图、主题、部门、风险类型、实体类型 |
| **检测** | 需要某个属性存在的概率 | 垃圾、欺诈、紧急、越狱、敏感数据 |
| **打分** | 答案落在有序量表上 | 严重度、相关性、质量、沮丧、适配 |
| **路由** | 一个类别决定下一条代码路径 | 工具调用、升级、模型路由、支持队列 |
| **搜索** | 要用自然语言查询找出匹配项 | 语义搜索、文档发现、候选生成 |
| **检索** | 工作流需要最相关的上下文或记录 | RAG 上下文、证据检索、知识查找 |
| **排序** | 要按语义相关性或质量给条目排序 | 搜索结果、推荐、候选优先级 |
| **核验** | 产物必须按特定失败模式检查 | 引用是否支撑、政策违规、工具调用错误、回复质量 |
| **ML 特征抽取** | 下游经典 ML 模型需要语义信号 | 购买意向、产品兴趣、竞争压力、流失信号 |
| **结构化数据抽取** | 要从非结构化输入里找回已知字段 | 候选人属性、订单字段、文档标签 |
